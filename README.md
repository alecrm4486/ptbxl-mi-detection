# ECG-based myocardial infarction detection (PTB-XL)

Work in progress: classifying normal vs myocardial infarction ECGs
with a 1D CNN in PyTorch, compared to a logistic regression baseline.

## Data
PTB-XL v1.0.3 (Wagner et al., 2020), available on PhysioNet.
Not included in this repository.
